# Тесты

Пирамида: `unit` → `component` → `integration`. Рядом с исходниками `*.test.ts(x)` не класть.

```bash
npm test                 # всё
npm run test:unit
npm run test:component
npm run test:integration
```

Правило: `.cursor/rules/test-pyramid.mdc`. Как писать: `.cursor/skills/test-pyramid/SKILL.md`.
